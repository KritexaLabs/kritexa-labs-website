## Architecture Pattern (Phase 1)

**Multi-page static website** with HTML partial composition build system.

### Build Flow
```
src/pages/<page>.html           (page content source)
    +
components/header.html          (shared header)
    +
components/footer.html          (shared footer)
    ↓
scripts/build.js                (Node.js composition)
    ↓
<page>/index.html               (production page — pure static HTML)
```

### URL Routing
All pages use folder-based `index.html` files. Server serves `/about` → `/about/index.html`. No client-side routing. No hash-based navigation in the new architecture.

### Transition Period (Phase 1 → Phase 3)
The extracted page content (`src/pages/`) still contains legacy `onclick="go('...')"` navigation calls from the original SPA. These remain functional via `js/navigation.js` (compatibility shim). They will be replaced with real `<a href="/page">` links in Phases 3–13.
